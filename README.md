# 画像コンバーター

ブラウザだけで動く画像形式変換ツールです。画像はサーバーに送信されず、すべて手元で処理されます。

- 入力: PNG / JPEG / WebP / GIF / BMP / SVG / AVIF / ICO(ブラウザが読み込める形式)
- 出力: PNG / JPEG / WebP / AVIF(対応ブラウザのみ) / GIF / BMP / ICO / PDF(1画像=1ページ)
- 複数ファイル、ドラッグ&ドロップ、貼り付け、画質・背景色・幅指定、ZIP一括保存、ライト/ダーク(黒ベース)テーマ切替
- 複数画像を縦/横に1枚へ結合(間隔指定・順番変更)
- 変換結果をクリップボードへコピー(PNG形式)
- 幅・高さの指定(縦横比維持の切替)
- ファイル名の変更(`{name}` `{n}` のパターン指定、個別編集)
- 回転(90°単位)とトリミング(比率指定可)

## 使い方
`index.html` をブラウザで開くだけ。ビルド不要・依存ライブラリなし。
GitHub Pages で公開する場合は Settings → Pages → Branch: main / root を選択。
